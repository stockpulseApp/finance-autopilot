Hardware wallets (Ledger, Trezor) store keys offline. Private keys never touch the internet. Cost: $50–200. Setup: Write 24-word seed phrase on *paper only*—never screenshots, never cloud storage. Verify every address on the device screen.

**Tweet 5:**
The Coldcard $38M exploit: Attackers modified firmware before devices shipped. Lesson—buy direct from manufacturers, verify tamper-evident packaging, and update firmware immediately after setup.

**Tweet 6:**
Software wallets (MetaMask, Trust Wallet) are hot wallets for active trading. Easier to use, higher risk. Strategy: Split holdings 80/20. Hardware wallet for long-term savings. Software wallet for spending/experiments.

**Tweet 7:**
The #1 mistake? Storing seed phrases digitally. Screenshots, cloud storage, encrypted notes—all get hacked. One example: User kept seed phrase in phone note. Phone stolen. Gone forever.

**Tweet 8:**
Other irreversible losses:
• Not testing with small amounts first
• Sending crypto to wrong addresses
• Forgetting hardware wallet PINs
• Falling for phishing links

One mistake = permanent loss. No customer service. No reversal.

**Tweet 9:**
Three-tier strategy:
1. Long-term reserves → Hardware wallet, offline
2. Liquid assets → Software wallet or exchange
3. Experimental funds → Small amounts, high-risk tolerance

If hot wallet gets compromised, you lose 10–20%, not everything.

**Tweet 10:**
Self-custody works if you treat it like a bank vault: document setup thoroughly, protect seed phrases like life savings, test everything at small scale first. Done right? You own your crypto. Done wrong? It's gone forever.
